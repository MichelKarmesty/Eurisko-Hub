# Internal Operations Service Hub

## Overview
A centralized, internal ticketing system designed to replace chaotic communication (WhatsApp, emails) with an auditable tracking workflow for IT, HR, and Maintenance requests.

## Documentation
All product logic, architectural decisions, and data models are documented in the `docs/` folder:
*   [Product Specification](docs/product-spec.md) - Problems, actors, and functional requirements.
*   [Architecture Draft](docs/architecture.md) - System boundaries, components, and resilience.
*   [Data Model](docs/data-model.md) - Domain entities, lifecycle rules, and storage patterns.
*   [Architecture Decision Records](docs/decisions/ADR-001.md) - Key technical decisions (e.g., ticket assignment strategy).
